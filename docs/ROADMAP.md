# Feuille de route

## v0.1 : prototype (fait)
- [x] Projet Godot 4.3, commandes clavier, souris et manette
- [x] Quartier généré, cycle jour / nuit
- [x] Joueur à la troisième personne, passants, personnages à qui parler
- [x] Système de missions piloté par des données JSON, 6 missions
- [x] Interface (argent, objectif, boussole, dialogues), sauvegarde

## v0.2 : réalisme visuel
- [x] Personnages humains réalistes et animés (Quaternius, CC0) : vêtements, wax, boubous, robes, foulards
- [ ] Vrais vêtements modélisés (boubous amples, pagnes, maillots) et morphologies plus naturelles
- [ ] Textures photo pour les murs, le crépi, le sable et le bitume (Poly Haven, CC0)
- [ ] Vraie forme des rues de Dakar à partir d'OpenStreetMap (Médina, Plateau)
- [ ] Bâtiments modélisés : façades, portes en fer forgé, climatiseurs, enseignes peintes
- [ ] Sable et poussière sur les trottoirs, déchets, charrettes, moutons
- [ ] Optimisation : LOD, culling, bâtiments fusionnés (indispensable pour Android)

## Consoles (après la v1.0)
Godot ne publie pas directement sur PlayStation, Xbox ou Switch. Il faut :
1. devenir développeur agréé auprès de Sony, Microsoft ou Nintendo (gratuit, mais sur dossier) ;
2. passer par une société de portage spécialisée Godot, par exemple **W4 Games** ou **Lone Wolf Technology** (payant).

On s'en occupe une fois le jeu terminé et publié sur PC et Android.
